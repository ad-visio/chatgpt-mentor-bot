# ChatGPT Mentor Bot

Telegram-бот-ассистент для управления напоминаниями, задачами и заметками. Реализован на `aiogram 3.8` с хранением данных в SQLite (через `aiosqlite`) и планировщиком `APScheduler`.

## Возможности
- Создание напоминаний с выбором даты/времени (таймзона UI — Europe/Kyiv, хранение — UTC).
- Тонкая настройка уведомлений (24 ч, 3 ч, 1 ч, 30 мин, 15 мин, в момент) и отложенные сигналы.
- Списки напоминаний: на сегодня, на завтра, все, архив.
- Задачи: быстрое создание из строки, просмотр активных записей и мягкое удаление.
- Список покупок: добавление позиций, отметка «куплено»/«удалить» и просмотр архива за 30 дней.
- Ритуалы: подборка пресетов с кнопками «Добавить в Напоминания» и учёт собственных заметок.
- Автоматическая пересоздача джоб APScheduler при старте, мгновенные ответы пользователю.

## Конфигурация окружения
- Python 3.10+
- Переменная окружения `BOT_TOKEN` передаётся через systemd unit.
- Часовой пояс для интерфейса: `Europe/Kyiv`.

## Запуск
Основной исполняемый файл — `bot.py`. При запуске бот сбрасывает Webhook и начинает polling, загружает незавершённые уведомления и пересоздаёт задачи планировщика.
